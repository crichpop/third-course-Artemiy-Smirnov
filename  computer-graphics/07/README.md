# ЛР7. Геометрические преобразования 2D

Запуск: открыть `index.html` в браузере. Вершины вводятся по одной на строке как `x,y` (не менее четырёх). На Canvas показаны исходная фигура, преобразованная фигура и центр `C=(cx, cy)`; по умолчанию `C=(0, 0)`.

Матрицы для векторов-столбцов:

```text
T(tx,ty) = [1 0 tx]    S(sx,sy) = [sx 0  0]    R(θ) = [cosθ -sinθ 0]
           [0 1 ty]               [0  sy 0]           [sinθ  cosθ 0]
           [0 0  1]               [0  0  1]           [  0     0  1]
```

Умножение: `C[i][j] = Σ(k=0..2) A[i][k]·B[k][j]`. Масштаб и поворот вокруг центра: `T(cx,cy)·S/R·T(-cx,-cy)`. Режим A применяет масштаб, поворот, перенос; режим B — масштаб, перенос, поворот. Исходные вершины не изменяются при повторном применении.

Ручной расчёт для `P0=(2,1)`, `θ=90°`, `T=(3,0)`, `S=(1,1)`, `C=(0,0)`:

| Режим | Вычисление | Результат |
|---|---|---|
| A: `T·R·P0` | `(2,1) → (-1,2) → (2,2)` | `(2,2)` |
| B: `R·T·P0` | `(2,1) → (5,1) → (-1,5)` | `(-1,5)` |

Результаты различаются, потому что умножение матриц некоммутативно. Проверены тождественные перенос и масштаб, повороты 360° и 90°, неподвижность выбранного центра, оба порядка, отражение при отрицательном масштабе и повторное применение от исходных вершин.
