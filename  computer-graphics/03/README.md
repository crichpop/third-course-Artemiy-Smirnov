1. Для каждой найденной точки (x, y) можно получить ещё семь точек: поменять координаты местами и изменить их знаки. Затем к координатам прибавляется центр окружности (cx, cy).
2. Окружность симметрична относительно осей и диагоналей. Поэтому достаточно вычислить точки одного сектора, а остальные получить отражением.
3. Это решающая переменная, которая помогает выбрать следующий пиксель. По её знаку определяется, оставить y прежним или уменьшить его на единицу. Начальное значение — d = 1 - r.
4. Если d >= 0, выбирается вариант SE, и y уменьшается на 1. Если d < 0, выбирается E, и y не меняется. Координата x увеличивается на каждом шаге.
5. При x = y мы достигаем границы одной восьмой окружности. Дальше будут получаться точки, симметричные уже построенным, поэтому продолжать вычисления не нужно.
6. Пока я не проверял это в программе. При одинаковых целочисленных радиусах и правильной реализации ожидается совпадение наборов пикселей. Для проверки нужно сравнить координаты, полученные обоими способами, на нескольких радиусах.
