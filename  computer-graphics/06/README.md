# ЛР6. Отсечение многоугольника

Запуск: открыть `index.html`. Многоугольник задан массивом вершин в `app.js`; среди примеров есть невыпуклый. Окно по умолчанию: `xmin=10`, `xmax=30`, `ymin=6`, `ymax=23`; проверяются `xmin<xmax`, `ymin<ymax`. На Canvas показаны исходный контур, окно и результат. Меню этапа и таблица показывают исходные вершины и результат после LEFT, RIGHT, TOP, BOTTOM. `canvas.clip()` не используется.

| S | P | Добавить |
|---|---|---|
| внутри | внутри | P |
| внутри | снаружи | пересечение |
| снаружи | внутри | пересечение, P |
| снаружи | снаружи | ничего |

Вертикальная граница: `t=(xграницы−S.x)/(P.x−S.x)`, `y=S.y+t(P.y−S.y)`. Горизонтальная: `t=(yграницы−S.y)/(P.y−S.y)`, `x=S.x+t(P.x−S.x)`.

Промежуточные вершины невыпуклого примера при окне по умолчанию; запись `x:y`:

| Этап | Число | Вершины по порядку |
|---|---:|---|
| Исходный | 8 | 4:3, 36:3, 36:27, 25:27, 25:13, 16:13, 16:27, 4:27 |
| LEFT | 8 | 10:3, 36:3, 36:27, 25:27, 25:13, 16:13, 16:27, 10:27 |
| RIGHT | 8 | 10:3, 30:3, 30:27, 25:27, 25:13, 16:13, 16:27, 10:27 |
| TOP | 8 | 10:6, 30:6, 30:27, 25:27, 25:13, 16:13, 16:27, 10:27 |
| BOTTOM | 8 | 10:23, 10:6, 30:6, 30:23, 25:23, 25:13, 16:13, 16:23 |

Ручной расчёт для LEFT (`x=10`): `S=(4;3)` снаружи, `P=(36;3)` внутри. `t=(10−4)/(36−4)=0,1875`; пересечение `(10; 3+0,1875·(3−3))=(10;3)`. Добавлены `(10;3)`, затем `(36;3)`.

| Обязательный тест | Результат |
|---|---|
| Полностью внутри | `inside`: 4 вершины сохранены |
| Полностью снаружи | `outside`: после LEFT пусто |
| Одна граница | `one`: обрезка по `x=10` |
| Две границы | `two`: обрезка по `x=10` и `x=30` |
| Четыре границы | `four`: результат равен окну |
| Вершина на границе | `vertex`: `(10;10)` сохранена |
| Ребро вдоль границы | `edge`: ребро на `x=10` сохранено |
| Невыпуклый исходный | `concave`: 8 вершин после отсечения |
| Пустой результат | `outside`: 0 вершин после BOTTOM |
