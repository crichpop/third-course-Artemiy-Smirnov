1) Запуск: открыть index.html в браузере.
2) API: https://jsonplaceholder.typicode.com/posts.
3) Используются GET, POST, PATCH и DELETE.
4) Список, поиск, id редактируемой записи и состояние запросов лежат в state.
5) Ошибки выводятся на странице. Пока идёт запрос, повторное сохранение заблокировано.
6) После успешного POST запись добавляется в список, после PATCH меняется, после DELETE удаляется. После перезагрузки изменения пропадают, потому что JSONPlaceholder их не хранит.
7) Для Network нужно проверить четыре метода. Скриншоты пока не сделаны.
