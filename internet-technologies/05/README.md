1) Запуск: npm install, npm start. Сервер работает на порту 3000.
2) Данные: 6 книг в массиве. После перезапуска новые книги пропадают.
3) Фильтры: /api/books?author=Пушкин и /api/books?available=true. Их можно использовать вместе.

| Метод | URL | Результат | Статусы |
|---|---|---|---|
| GET | /api/books | список | 200, 400 |
| GET | /api/books/:id | одна книга | 200, 404 |
| POST | /api/books | новая книга | 201, 400 |
| GET | /api/info | информация о сервере | 200 |
| любой | другой адрес | ошибка | 404 |

4) Пример POST: `curl -X POST http://localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":"Новая книга","author":"Автор","available":true}'`.
5) Ошибочный POST без полей возвращает 400. Несуществующий id и неизвестный адрес возвращают 404.
