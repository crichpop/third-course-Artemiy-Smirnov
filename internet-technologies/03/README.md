1. Я использовал https://jsonplaceholder.typicode.com/users. С него приходит список пользователей в формате JSON.
2. Отправляется метод GET, потому что нужно получить данные с сервера.
3. Состояние хранится в объекте state в файле app.js. В нём находятся список пользователей, текст поиска, ошибка и признаки загрузки.
4. До загрузки показывается предложение загрузить данные. Во время запроса появляется «Загрузка...». После успешного ответа выводятся карточки пользователей, а при ошибке — сообщение о проблеме. Если поиск ничего не нашёл, об этом тоже появляется сообщение.
5. Запрос находится внутри try/catch. Сначала проверяется response.ok: если сервер вернул ошибку, она передаётся в catch. Сообщение выводится на странице. В блоке finally выключается состояние загрузки, поэтому можно попробовать ещё раз.
6. Поиск работает по имени, username и email без учёта регистра. Для фильтрации используется filter(), поэтому исходный массив пользователей не меняется.
7. При успешном запросе к /users сервер вернул код 200 и массив из 10 пользователей. Метод запроса — GET, тип ответа — application/json. При проверке неправильного адреса сервер вернул 404, а на странице появилось сообщение об ошибке. После возвращения правильного адреса загрузка снова заработала.
